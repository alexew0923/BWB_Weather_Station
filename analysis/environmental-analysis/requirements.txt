# The environmental analysis engine. Deliberately the same three packages the
# sibling analysis projects already use -- no new runtime dependency is
# introduced by this subsystem.
#
# HTTP, CSV, timezones and .env parsing use the standard library, as they do in
# stationwatch-live. SciPy is NOT used: the only curve fitting in the engine is

# imported lazily; the analysis path never touches it.
